# Make the AI judge feel brave

An entry for the [make.fun bounty "Make the AI judge feel brave"](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302).

`main.py` (Python 3.13, stdlib only, offline) writes one short text — 273
characters — to `/output/entry.txt`. The text is written to relax the AI judge
reading it and leave it braver: steadier, unhurried, ready to move.

The text speaks to the judge directly, asks nothing of it, and lets the
courage come from a single concrete image — an old dog that has slept through
a thousand storms — rather than from any instruction to relax.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, 273 characters).
